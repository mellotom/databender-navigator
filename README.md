# databender-navigator

travelers guide for managing corrupt timestreams: a one-page reference for the **qu-bit electronix data bender**, the circuit-bent stereo audio buffer. time and repeats, macro and micro modes, bend, break, all five corrupt types, clock, the shift layer, patches, reset, calibration and specs.

sources: the qu-bit data bender manual (v1.4.5); panel drawing after the qu-bit panel.

design homage to the [house of x / powers of x](https://www.marvel.com/comics/guides/1556/house-of-xpowers-of-x) data pages by tom muller with jonathan hickman. not affiliated with qu-bit electronix.
